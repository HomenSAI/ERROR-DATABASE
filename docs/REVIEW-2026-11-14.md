## Замечания и что сделано
1. **Схема не проверялась в CI.** `validate.py` не проверяет `http_status` (400–599), `tags`, `examples`, `prompt`, `channel` —
   их держит только схема. Добавлен `tests/test_schema.py` (каждый файл + отрицательный пример), в `validate.yml` ставится `jsonschema`.
2. **Действия GitHub в `validate.yml` не закреплены по SHA** (в `pages.yml`/`release.yml` закреплены). Закреплены те же SHA.
3. **Аудитория только `user`.** Уровни `admin`/`developer` описаны в архитектуре, но не используются: тексты для разработчика
   (внутренние детали) по правилу §9 в публичную базу не идут — это верно; при переносе кодов других проектов (ERR.import-others)
   проверить, что внутренние детали остаются в продуктах.
4. **`http_status` указан у 1 кода из 247.** Для кодов веба Rent (`web_*` → RENT-WEB) статус известен (400/403/413) — стоит
   заполнить при следующем экспорте из Rent (`scripts/export_error_database.py`).
5. **VPN: 13 кодов из ~942** у Auto VPN — перенос идёт PR-ами `vpn/*` (ERR.import-others), не ошибка базы.
6. **Python в CI 3.13**, `requires-python >=3.10` — намеренно шире 3.14 (библиотека для разных продуктов, в т. ч. роутера). Оставлено.
