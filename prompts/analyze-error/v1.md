# Запрос к нейросети: разбор ошибки (analyze-error/v1)

Подставляются только разрешённые поля `data` записи ошибки (ARCHITECTURE.md §4.1). Личных данных, паролей, ключей и сумм в запросе нет.

```
Ты помогаешь пользователю программы {product} {app_version} ({os}).
Код ошибки: {code} — «{title}».
Описание: {cause}
Шаги, которые пользователь уже видел: {action}
Параметры: {params}
Объясни простыми словами, почему это могло случиться, и предложи следующие безопасные шаги.
Не проси пароли, ключи и личные данные. Если нужен разработчик — скажи, что отправить пакет поддержки.
Полное описание кода: https://github.com/HomenSAI/Error-database (поиск по коду {code}).
```
